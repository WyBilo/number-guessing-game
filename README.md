Number Guessing Game

📌 Overview

This is a simple Python-based number guessing game where the user attempts to guess a randomly generated number within a limited number of attempts.

The project focuses on building strong fundamentals in Python, including program structure, input validation, and control flow.

⸻

🎯 Features

* Random number generation (1–10)
* Input validation (handles invalid and out-of-range input)
* Attempt tracking system
* High / Low feedback after each guess
* Win / Lose conditions
* Clean function-based structure

⸻

🧠 Concepts Used

* Functions
* Loops (while)
* Conditionals (if / elif / else)
* Exception handling (try / except)
* User input validation
* Random module
* Program flow control

⸻

🛠️ How It Works

1. The program generates a random number between 1 and 10
2. The user is prompted to guess the number
3. After each guess:
    * The program tells the user if the guess is too high or too low
4. The user has a maximum of 3 attempts
5. The game ends when:
    * The user guesses correctly ✅
    * The user runs out of attempts ❌
